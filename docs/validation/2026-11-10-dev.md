## Docker 建置與 runtime

```bash

docker compose run --rm ros-smoke
docker compose run --rm dev-check
```

最終映像、實際 runtime 輸出與狀態碼將在本輪驗收完成後填入。

最終 smoke 映像已重跑：

- `docker compose run --rm ros-smoke`：exit 0，輸出 `PASS: ROS 2 message received between two container processes`，無 teardown traceback。見 [原始輸出](2026-11-10-smoke.log)。
- `docker compose run --rm ros-smoke python3 /opt/itri/ros_smoke.py sub`：預期的失敗，exit 1，輸出 `ROS 2 smoke timed out waiting for the expected message`。此容器沒有 publisher，確認不能收不到訊息卻通過。見 [原始輸出](2026-11-10-smoke-timeout.log)。

初次 smoke 收發成功，但發布端 teardown 印出 `ExternalShutdownException`／重複 shutdown。已修正預期終止處理，檢查發布端結束碼，並安排以最終映像重跑；不把初次輸出當成最終通過紀錄。
