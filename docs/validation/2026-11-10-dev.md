## 常駐開發入口

已實際執行 `docker compose up -d dev`，exit 0，`itri-retail-dev-1` 為 Up。隨後 `docker compose exec -T dev bash -ec 'source /opt/itri/setup.bash; pwd; id; test "$ROS_DISTRO" = humble; test -w /workspace/ros2_ws'` exit 0，工作目錄 `/workspace/ros2_ws`。

可在宿主機直接 `docker compose exec dev bash`；結束工作用 `docker compose stop dev`。沒有啟動真機、模型、Nav2 或 MoveIt 節點。
